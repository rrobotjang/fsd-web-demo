# FSD Web Demo - Colab Training Schedule
## 600 CU/월 최적화

### 월간 CU 배분 (T4 기준)
| 주차 | 작업 | CU 소모 | 누적 |
|------|------|---------|------|
| 1주차 | U-Net 세그멘테이션 학습 | 40 CU | 40 |
| 2주차 | YOLOv8 파인튜닝 | 30 CU | 70 |
| 3주차 | Qwen 2.5 LoRA 파인튜닝 | 100 CU | 170 |

### 모델 상세

#### 1. U-Net 세그멘테이션 (40 CU)
- **데이터셋**: KITTI Road (289 training images)
- **에포크**: 50
- **배치**: 8
- **예상 시간**: ~2시간 × 2회 = 4시간
- **출력**: `lane.onnx`

#### 2. YOLOv8 파인튜닝 (30 CU)
- **데이터셋**: KITTI Detection (7,481 images)
- **에포크**: 30
- **배치**: 16
- **예상 시간**: ~1.5시간 × 2회 = 3시간
- **출력**: `detection.onnx`

#### 3. Qwen 2.5 LoRA (100 CU)
- **데이터셋**: 자율주행 설명 데이터 (컬스텀)
- **에포크**: 3
- **배치**: 4
- **예상 시간**: ~30시간
- **출력**: `qwen_adapter/`

### 주의사항
- Colab 세션 제한: 최대 6시간/세션
- 세션 종료 시 자동 저장 필수
- `gdrive` 마운트로 모델 영구 저장
- 학습 중간 체크포인트 필수
