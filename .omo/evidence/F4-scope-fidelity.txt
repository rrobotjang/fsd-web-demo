SCOPE DRIFT SUMMARY
-------------------
1. colab/ training artifacts live in-repo (guardrail #7 WARN): repository contains model
   TRAINING code (notebooks + scripts), though the runtime path never executes it. This
   is exactly the ambiguity "모델 학습 코드 (추론만)" was meant to prevent at app scope;
   colab/ is the provenance directory, not app code. Documented as scope note, not failure.
2. "주행 경로 표시" (Must-have #4) is the ONE genuinely unmet product promise: no path
   planning visualization. Mitigation: situation classification provides driving
   decision context in text form via Qwen narrative.
3. No out-of-scope features detected anywhere else (auth, PG, deploy infra, training at
   runtime — all absent). Guardrail discipline otherwise exemplary.
